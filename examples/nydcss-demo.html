nydcss is a modern CSS framework that synthesizes the best features from 20+ leading CSS libraries. It provides a complete design token system, reset, layout utilities, components, and animations in one cohesive package.
Dark mode uses CSS custom properties that are automatically swapped via @media (prefers-color-scheme: dark). You can force a theme with data-theme="dark" or data-theme="light" on the <html> element.
Yes. nydcss is framework-agnostic plain CSS. Import it once and use the class names anywhere. No JavaScript required. The modular architecture also lets you import only the layers you need.

Prose (Long-form Content)

Article Title

Use .nyd-prose on any container to get beautifully styled long-form content. It handles headings, paragraphs, lists, blockquotes, tables, and code blocks automatically.

Section Heading

All headings, spacing, and vertical rhythm are handled so you don't need to add classes to each element. Works perfectly for Markdown-rendered content, CMS output, or documentation pages.

  • Bulleted lists get proper indentation and bullets
  • Nested lists work too
  • Links are styled automatically
