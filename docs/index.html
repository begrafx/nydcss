What IS it?

Have you ever started a project, and looking at your CSS options, you wanted the best parts of this one, and that one, and this piece of this other one, but of course trying to run, say Bootstrap and Bulma at the same time would be more of a headache than a solution. Introducing: NydCSS. We've taken what we consider the best parts of over 20 of the best CSS libraries out there, and blended them into one cohesive, zero-dependency stylesheet.

Getting Started

CDN — fastest way to start

Add one line to your <head> and you're done:

html
<link rel="stylesheet" href="https://unpkg.com/nydcss/dist/nyd.css">

For production, use the minified build (~13KB gzip):

html
<link rel="stylesheet" href="https://unpkg.com/nydcss/dist/nyd.min.css">

npm

$ npm install nydcss
css
/* Import everything */
@import "nydcss/dist/nyd.css";

/* Or cherry-pick layers (critical CSS pattern) */
@import "nydcss/src/nyd-tokens.css";
@import "nydcss/src/nyd-reset.css";
@import "nydcss/src/nyd-layout.css";
@import "nydcss/src/nyd-components.css";

Minimal HTML boilerplate

html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My App</title>
  <link rel="stylesheet" href="nyd.css">
</head>
<body>
  <div class="container">
    <h1>Hello, nydcss</h1>
    <button class="btn btn-primary">Get started</button>
  </div>
</body>
</html>
✅
No JavaScript needed. All components work with pure CSS. JavaScript is only needed for interactive behavior like modals, dropdowns, and accordions — and those are tiny, framework-agnostic snippets you write yourself.

Architecture

nydcss is organized into eight independent layers. Each layer imports cleanly from the previous. You can stop at any layer.

LayerFileWhat it does
1 · Tokensnyd-tokens.cssAll CSS custom properties — colors, spacing, type, shadows, z-index, transitions
2 · Resetnyd-reset.cssCross-browser normalize, box-sizing, focus-visible, selection, scroll-behavior
3 · Basenyd-base.cssStyled semantic HTML: headings, blockquote, code, kbd, mark, table. Plus .nyd-prose
4 · Layoutnyd-layout.cssContainer, flexbox, grid, auto-grid, gap, stack, cluster, sidebar
5 · Utilitiesnyd-utilities.cssMargin, padding, width, height, text, font, color, border, radius, shadow, opacity
6 · Componentsnyd-components.css30+ UI components: buttons, forms, cards, nav, tables, modals, toasts, and more
7 · Animationsnyd-animations.css15 keyframes + utility classes + transition + transform utilities
8 · Responsivenyd-responsive.cssBreakpoint prefixes (sm: md: lg: xl:), visibility helpers, print, dark mode helpers
💡
Specificity philosophy: nydcss uses flat, single-class selectors throughout. No !important (except the intentional .hidden override). Overriding any style is straightforward.

Design Tokens

Every visual decision in nydcss is expressed as a CSS custom property. Override any token globally at :root or locally at any element scope to create custom themes without touching the source.

css
/* Global rebrand — purple theme */
:root {
  --nyd-color-primary:       #7c3aed;
  --nyd-color-primary-hover: #6d28d9;
  --nyd-color-primary-light: #faf5ff;
  --nyd-color-primary-alpha: rgba(124, 58, 237, 0.15);
  --nyd-font-sans: 'Inter', system-ui, sans-serif;
  --nyd-radius-lg: 12px;
}

/* Scoped — only inside .admin-panel */
.admin-panel {
  --nyd-color-primary: #0ea5e9;
}

Dark Mode

nydcss uses CSS custom properties to implement dark mode. By default it respects the user's system preference via prefers-color-scheme: dark.

Force a theme

html
<!-- Always dark -->
<html data-theme="dark">

<!-- Always light -->
<html data-theme="light">

<!-- Follow system (default) -->
<html>

Toggle with JavaScript

js
function toggleTheme() {
  const html = document.documentElement;
  const isDark = html.dataset.theme === 'dark';
  html.dataset.theme = isDark ? 'light' : 'dark';
  // Persist preference
  localStorage.setItem('theme', html.dataset.theme);
}

// Restore saved preference on load
const saved = localStorage.getItem('theme');
if (saved) document.documentElement.dataset.theme = saved;

Component-level dark override

css
/* Force dark appearance for one component */
.my-dark-card {
  --nyd-color-surface:    #161b27;
  --nyd-color-text:       #e6edf3;
  --nyd-color-border:     rgba(255,255,255,.1);
}

Reset & Normalize

nydcss applies an opinionated reset inspired by normalize.css, sanitize.css, and modern browser conventions. You get:

FeatureDetail
Universal box-sizingbox-sizing: border-box on *, *::before, *::after
Zero marginsAll elements start with margin: 0; padding: 0
Responsive mediaimg, video, svg → max-width: 100%
Font inheritanceButtons and inputs inherit the document font
Focus visible:focus-visible ring, :focus:not(:focus-visible) suppressed
Smooth scrollingscroll-behavior: smooth on html
Font smoothing-webkit-font-smoothing: antialiased
Disabled statesAutomatic cursor: not-allowed; opacity: .5
Selection colorUses --nyd-color-primary-alpha
ℹ️
The reset is designed to be non-destructive. It does not strip list styles from <ul> elements globally — only the utility class .list-none does that.

Tooltips

Pure CSS tooltips using the data-tooltip attribute. No JavaScript required.

html

<!-- Positions: top (default), bottom, left, right -->

⚠️
Accessibility note: CSS tooltips only show on hover. For keyboard users, add a visible label or use aria-describedby with a visually hidden element alongside the CSS tooltip.

Adding custom components

Create new components that follow the nydcss convention — use design tokens instead of raw values so they automatically adapt to dark mode and theme overrides:

css
/* ✅ Good — uses tokens, works in all themes */
.my-panel {
  background: var(--nyd-color-surface-2);
  border: 1px solid var(--nyd-color-border);
  border-radius: var(--nyd-radius-xl);
  padding: var(--nyd-space-6);
  color: var(--nyd-color-text);
}

/* ❌ Avoid — hardcoded values break dark mode */
.my-panel {
  background: #f9fafb;
  border: 1px solid #e5e7eb;
}

Critical CSS Pattern

nydcss's modular architecture makes it easy to inline above-fold critical CSS and async-load the rest, inspired by Addy Osmani's critical methodology and filamentgroup/loadCSS.

html
<head>
  <!-- Inline critical CSS: tokens + reset + layout -->
  <style>
    @import "nydcss/src/nyd-tokens.css";
    @import "nydcss/src/nyd-reset.css";
    @import "nydcss/src/nyd-layout.css";
  </style>

  <!-- Async-load the rest -->
  <link rel="preload" href="nydcss/dist/nyd.css" as="style"
        onload="this.onload=null;this.rel='stylesheet'">
  <noscript>
    <link rel="stylesheet" href="nydcss/dist/nyd.css">
  </noscript>
</head>
⚡
Performance tip: The tokens + reset layers are only ~12KB combined. Inlining them eliminates render-blocking CSS for above-fold content while the full framework loads asynchronously.
